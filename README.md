# 🐛 TradieScribe Bug Reports

Welcome to the TradieScribe public bug reporting repository! 👋

## What is this repository for?

This repository is dedicated to tracking bugs and missing/incomplete functionality in TradieScribe. It provides a centralized place for users to report issues they encounter while using the application.

**Important:** This repository is specifically for **bugs and missing functionality only** - not for feature requests. If you have ideas for new features, please use our [Discussions](https://github.com/TradieScribe/bug-reports-public/discussions) forum instead.

## How to report a bug

If you've encountered a bug or problem with TradieScribe:

1. **Check existing issues** - Search through [existing issues](https://github.com/TradieScribe/bug-reports-public/issues) to see if someone has already reported the same problem
2. **Create a new issue** - If your bug hasn't been reported yet, [create a new issue](https://github.com/TradieScribe/bug-reports-public/issues/new/choose) and select the appropriate template:
   - **Bug Report** - For reporting bugs, errors, or unexpected behavior
   - **Missing or Incomplete Functionality** - For reporting functionality that should exist but doesn't, or exists but is incomplete

When creating an issue, please provide as much detail as possible, including:
- A clear description of the problem
- Steps to reproduce the issue
- Expected vs. actual behavior
- Screenshots or screen recordings (if applicable)
- Your TradieScribe version and platform

## Not sure if you should open an issue?

If you're uncertain whether something is a bug or you'd like to discuss a problem before opening an issue, please start a [Discussion](https://github.com/TradieScribe/bug-reports-public/discussions) first. Our community can help you:

- Clarify whether something is a bug or expected behavior
- Troubleshoot issues before creating a formal bug report
- Determine if a problem is related to your specific setup
- Get a second opinion on whether functionality is missing or incomplete

## Guidelines

- **Be respectful** - Remember there are real people behind the project
- **Be specific** - The more details you provide, the easier it is to fix the issue
- **One issue per report** - Don't bundle multiple unrelated bugs into a single issue
- **Follow the templates** - Use the provided issue templates to ensure all necessary information is included

## Questions?

If you have questions about TradieScribe or need general support, please visit our [Discussions](https://github.com/TradieScribe/bug-reports-public/discussions) forum.

Thank you for helping make TradieScribe better! 🙏
